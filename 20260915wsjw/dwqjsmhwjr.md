# 女性霉菌感染怎么治疗

> 更新时间：2026-09-15 (UTC+8)

女性霉菌感染可通过克霉唑栓、氟康唑口服、碳酸氢钠坐浴、保持外阴干燥、避免性生活等方式治疗。霉菌感染通常由阴道菌群失衡、免疫力下降、抗生素滥用、糖尿病控制不佳、贴身衣物不透气等原因引起。

## 1、克霉唑栓：

克霉唑栓是治疗霉菌性阴道炎的常用局部抗真菌药物，主要成分为克霉唑，能抑制真菌细胞膜合成。使用前需清洁外阴，将栓剂置于阴道深部，疗程通常为3-7天。用药期间可能出现局部灼热感，需避免月经期使用，孕妇应在医生指导下用药。

## 2、氟康唑口服：

氟康唑是系统性抗真菌药物，通过抑制真菌麦角固醇合成发挥作用。单次大剂量口服150mg可治疗单纯性霉菌感染，复杂性感染需延长疗程。该药可能引起胃肠道不适或肝功能异常，用药期间需监测肝功能，禁止与特非那定等药物联用。

## 3、碳酸氢钠坐浴：

4%碳酸氢钠溶液坐浴能改变阴道酸碱环境，抑制霉菌生长。每日1-2次，每次10-15分钟，水温控制在40℃以下。该方法适合辅助治疗，但不能替代抗真菌药物，坐浴后需彻底擦干外阴，避免局部潮湿。

## 4、保持外阴干燥：

霉菌在潮湿环境中易繁殖，建议选择纯棉透气内裤并每日更换，避免穿紧身裤或化纤材质衣物。如厕后从前向后擦拭，运动后及时清洁外阴。可使用吹风机低温档吹干外阴，但需保持20厘米以上距离防止烫伤。

## 5、避免性生活：

治疗期间禁止性生活可防止交叉感染和黏膜损伤。伴侣需同步检查，确诊感染需共同治疗。恢复性生活后建议使用避孕套，性交前后注意清洁。反复感染者应排查糖尿病等基础疾病。

霉菌感染易在月经前后复发，建议治疗后连续3个月经周期后复查白带。日常可适量摄入无糖酸奶补充益生菌，避免长期使用护垫。选择宽松透气的纯棉衣物，洗涤时用60℃以上热水杀菌。适度运动增强免疫力，控制血糖水平。治疗期间禁止盆浴、游泳等可能引起交叉感染的活动，症状消失后仍需完成规定疗程。
