# 【用药小贴士】停药非小事

> 更新时间：2026-09-17 (UTC+8)

注意啦，注意啦！最新一期的“用药小贴士”文章即将来啦！

今天，我们要讲的是：**停药非小事**。

**大家在用药过程中难免会有疑问：这药该用多长时间？感觉病好了是否该停药？**

大家别着急，你们的这些疑问，今天都会得到解答的、

**一、症状消失后即可停用的药物**

1. 解热镇痛药

如布洛芬、对乙酰氨基酚等，除用于类风湿性疾病外只在症状发作时使用，长期应用反而会对人体器官造成损害；

2. 止泻药

对于饮食不洁、感冒等引起的吐泻，采用“速战速决”的手段；

3. 胃肠解痉药

如阿托品、颠茄片吃一两次症状若消失，就不用吃第三次，症解药停；

4. 安眠药

对于偶尔失眠的患者，失眠发作时可以服用1-2片，若长期服用会产生依赖性及耐药性。

**二、需按疗程服用的药物**

1. 抗感染类药物

对于一些疾病，如肺炎、支气管炎，应用抗菌药物要使用足够疗程，一般在病情好转后再使用2-3天，或者根据CT检查情况用药；

2. 抗结核类药物

用药疗程有一年、一年半或更长时间的，需要患者长期规律用药，若治疗不规范、疗程不足均可导致治疗失败；

3. 抗溃疡药物

胃、十二脂肠溃疡的治疗时间一般为4-8周，通过胃镜检查破损溃疡已愈合时，主张再维持治疗一段时间，降低溃疡复发率；

4. 抗甲状腺功能亢进药

在症状消失后，需要在维持治疗1-2年，停药过早易复发；

5. 其他

还有一些如治疗癫痫、类风湿性关节炎、丝虫病的药物在服用过程中不能着急停药，要按疗程遵医嘱用药。

**三、需长期服用的药物**

对于一些慢病目前尚无有效的治疗手段彻底治愈，需要长期甚至终身服药，如高血压、糖尿病、抗精神病药等。

一些初始用药的患者，往往在疾病控制后，自作主张，随意停用药物。导致病情反弹复发，增加危险性。

**四、不能突然停用的药物**

1. 治疗高血压、心律失常的药物

如普萘洛尔，美托洛尔等，突然停药会使血压反弹，严重者会引起心绞痛、心肌梗死而死亡；

2. 糖皮质激素类药物

如果突然停药，体内腺体分泌的激素来不及做出相应增加，使原发病复发；

3. 抗癫痫类药物

如苯巴比妥、苯妥英钠等，突然停药会诱发癫痫，甚至出现癫痫持续状态；

4. 胰岛素类药物

使用胰岛素治疗糖尿病，特别是胰岛素依赖性糖尿病，不能突然停药，这样会加重低血糖风险，严重者会出现酮症酸中毒。

所以，“药不能停”这句话，不只是一句玩笑话，在服药期间，一定要谨记以上的用药知识。更需要严格遵守医嘱哦！
